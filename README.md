# TicketDesk

TicketDesk is a FastAPI-based IT support ticket management API being deployed as an AWS cloud POC.

## Current Stack

- Python / FastAPI
- PostgreSQL
- SQLAlchemy
- Docker
- Docker Compose
- AWS ECS Fargate
- Amazon ECR
